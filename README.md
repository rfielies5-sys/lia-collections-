
# LIA Collections - Static Web App (ready for GitHub + Vercel)

This package contains a ready-to-deploy static web app for LIA Collections.
Features:
- Brand colors (red, black, white)
- Sample products (Tee, Cap, Hoodie, Sunglasses, Watch)
- Pre-order badge and filter
- Add to cart with persistent `localStorage`
- Sandbox checkout (simulated, redirects to success page)
- Contact footer with Rosina Fielies details

How to deploy:
1. Create a new GitHub repository (lia-collections)
2. Upload contents of this ZIP (all files and folders)
3. Connect repository to Vercel (Import Project) and Deploy
4. After deployment completes, Vercel will provide the live URL (e.g. https://lia-collections.vercel.app)
